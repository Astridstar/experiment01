# Sample data for the CLV / RFM transformation

This directory ships reproducible, intentionally-dirty sample data that matches
the input contract of
[`transformations.gold.customer_lifetime_value.build_customer_lifetime_value`](../src/data_cleansing_experiment01_etl/transformations/gold/customer_lifetime_value.py).

## Files

| File                | Rows        | Description                                                                 |
|---------------------|-------------|-----------------------------------------------------------------------------|
| `customers.csv`     | 5,000       | `customer_id, full_name, country, signup_date`                              |
| `orders.csv`        | ~31,000     | `order_id, customer_id, order_ts, currency`                                 |
| `order_items.csv`   | ~87,000     | `order_id, product_id, category, quantity, unit_price`                      |
| `generate_sample_data.py` | —    | Seeded generator; re-run to regenerate at any size                          |

All three files are generated by a single seeded Python script, so the exact
bytes are reproducible. Referential integrity holds: every `order.customer_id`
exists in `customers`, and every `order_items.order_id` exists in `orders`.

## Dirty traits (on purpose)

The data deliberately mirrors what real bronze data looks like so the
normalization paths in the transformation actually execute:

- **Names** — mixed casing and leading/trailing spaces (e.g. `"  alice tan "`,
  `"BOB LEE"`, `"Carol Lim"`). Exercises `normalize_name`.
- **Countries** — 43 raw variants across `sg / SG / Singapore / SINGAPORE`,
  `us / USA / usa`, `uk / UK / GB / gb`, `cn / China`, `jp / JP / japan`, etc.
  Exercises upper/trim and downstream country-code mapping if you enable it.
- **Currencies** — 18 raw variants: `sgd / SGD / " sgd"`, `rmb / RMB / cny`,
  `yen / YEN / JPY`, `usd / USD`, etc. Exercises `normalize_currency_code`.
- **Customers with zero orders** — ~7% of customers have no rows in
  `orders.csv`. Exercises the left-join / null-metric code path.
- **Recency spread** — per-customer timestamp distributions are skewed
  differently so you get a healthy mix of active, lapsed and at-risk
  customers.
- **Category skew** — each customer has a preferred 1–4 category shortlist
  they pick from 70% of the time. Makes the `top_categories` ranking
  meaningful rather than uniform noise.
- **Cross-currency orders** — ~15% of a customer's orders use a different
  currency from their usual one, e.g. travel purchases.

## Regenerating

From this directory:

```bash
# Defaults: 5,000 customers, seed=42, as_of=2024-04-23
python3 generate_sample_data.py

# Larger dataset
python3 generate_sample_data.py --customers 50000 --seed 7

# Different reporting date
python3 generate_sample_data.py --as-of 2025-01-01

# See all knobs
python3 generate_sample_data.py --help
```

The script uses only the Python standard library — no Faker, no Spark, no
network.

## Loading the data

### Locally with PySpark

```python
from pyspark.sql import SparkSession
from pyspark.sql.types import (
    StructType, StructField, IntegerType, StringType, TimestampType, DecimalType,
)

spark = SparkSession.builder.master("local[*]").getOrCreate()

customers = (spark.read
    .option("header", True)
    .schema(StructType([
        StructField("customer_id", IntegerType(), False),
        StructField("full_name",   StringType(),  True),
        StructField("country",     StringType(),  True),
        StructField("signup_date", StringType(),  True),
    ]))
    .csv("sample_data/customers.csv"))

orders = (spark.read
    .option("header", True)
    .schema(StructType([
        StructField("order_id",    IntegerType(),   False),
        StructField("customer_id", IntegerType(),   False),
        StructField("order_ts",    TimestampType(), False),
        StructField("currency",    StringType(),    True),
    ]))
    .csv("sample_data/orders.csv"))

items = (spark.read
    .option("header", True)
    .schema(StructType([
        StructField("order_id",   IntegerType(),       False),
        StructField("product_id", IntegerType(),       False),
        StructField("category",   StringType(),        False),
        StructField("quantity",   IntegerType(),       False),
        StructField("unit_price", DecimalType(18, 2),  False),
    ]))
    .csv("sample_data/order_items.csv"))

from datetime import date
from transformations.gold.customer_lifetime_value import (
    CLVConfig, build_customer_lifetime_value,
)

clv = build_customer_lifetime_value(
    customers, orders, items,
    CLVConfig(as_of_date=date(2024, 4, 23)),
)
clv.show(20, truncate=False)
```

### Inside a Databricks workspace

Upload the three CSVs to a Unity Catalog volume, e.g.:

```
/Volumes/dev/experiment01/samples/customers.csv
/Volumes/dev/experiment01/samples/orders.csv
/Volumes/dev/experiment01/samples/order_items.csv
```

Then in a notebook:

```python
customers = spark.read.option("header", True).csv(
    "/Volumes/dev/experiment01/samples/customers.csv"
).selectExpr(
    "CAST(customer_id AS INT) AS customer_id",
    "full_name", "country", "signup_date",
)

orders = spark.read.option("header", True).csv(
    "/Volumes/dev/experiment01/samples/orders.csv"
).selectExpr(
    "CAST(order_id AS INT) AS order_id",
    "CAST(customer_id AS INT) AS customer_id",
    "CAST(order_ts AS TIMESTAMP) AS order_ts",
    "currency",
)

items = spark.read.option("header", True).csv(
    "/Volumes/dev/experiment01/samples/order_items.csv"
).selectExpr(
    "CAST(order_id AS INT) AS order_id",
    "CAST(product_id AS INT) AS product_id",
    "category",
    "CAST(quantity AS INT) AS quantity",
    "CAST(unit_price AS DECIMAL(18,2)) AS unit_price",
)
```

Or persist them as managed tables once and reuse:

```sql
CREATE TABLE dev.experiment01.customers_sample
  AS SELECT * FROM read_files('/Volumes/dev/experiment01/samples/customers.csv',
                              format => 'csv', header => true);
```

## Schema reference

```text
customers
    customer_id   INT       PK, 1-based contiguous
    full_name     STRING    mixed case, possible leading/trailing spaces
    country       STRING    mixed-case 2/3-letter codes or full names
    signup_date   DATE      YYYY-MM-DD

orders
    order_id      INT       PK, starts at 1_000_000
    customer_id   INT       FK -> customers.customer_id
    order_ts      TIMESTAMP YYYY-MM-DD HH:MM:SS
    currency      STRING    mixed-case 3-letter codes (sgd, SGD, rmb, yen, ...)

order_items  (many per order)
    order_id      INT       FK -> orders.order_id
    product_id    INT       not unique; category-specific
    category      STRING    one of 14 predefined categories
    quantity      INT       1..10, heavily weighted to 1-2
    unit_price    DECIMAL(18,2)
```
